# NextJS + Typescript + Redux Toolkit Query + Jest (with react-testing-library) + SCSS

## Features
- Redux Toolkit Query
- SCSS (used as CSS modules)
- Jest with react-testing-library
- SVGR (so .svg files can be treated as React components, which is more convenient for styling)
- Eslint

## More about Eslint plugins
- eslint-config-next (which includes eslint-plugin-react, eslint-react-plugin-hooks, eslint-plugin-next, eslint-typescript \(with ts-parser\), eslint-plugin-jsx-a11y)
- eslint-typescript (as a separate module, since strict version of rules is used, as well as stylistics rules)
- eslint-config-airbnb (which includes eslint-plugin-import)
- eslint-plugin-jest-dom
- eslint-plugin-testing-library (both for testing rules)
